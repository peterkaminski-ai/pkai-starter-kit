# pkai-starter-kit

A starter kit for building your own personal AI assistant — a persistent, file-based companion you talk to through Claude Code.

**Home page:** https://peterkaminski.ai/starter-kit

This kit is a **reference library, not a house**. You don't move into it — you (and Claude Code, doing the heavy lifting) *read* it and build your own assistant from it: an **assistant home** for your assistant's persona and memory, and a **headquarters** for your projects and working files. The build takes one guided conversation.

## If you're a person

Don't start here — start with the home page, or go straight to **`START-HERE.md`**, the short instructions you'll drive. The shape of it:

1. Check **`REQUIREMENTS.md`** — what you need before you begin (a Claude Pro or Max account, Claude Code installed, a couple of basics).
2. Make an empty **headquarters** folder and start Claude Code in it.
3. Paste in one kickoff message. Claude downloads this kit, reads it, and helps you build your assistant — with you driving every step.

## If you're a Claude reading this

You've been asked to help a person set up their own assistant. **Read `BUILD.md`** — it's addressed to you.

## What's inside

- **`START-HERE.md`** — the setup instructions, addressed to the person. They drive; Claude does the heavy lifting.
- **`BUILD.md`** — the build reference, addressed to the Claude doing the building.
- **`REQUIREMENTS.md`** — what you need: account, computer basics, and the two *surfaces* (a chat surface and a review surface).
- **`ARCHITECTURE.md`** — the shape of what you're building: assistant home, headquarters, and how they relate.
- **`WAIVER.md`** — the participation waiver; agreeing to it is the first step of setup.
- **`personas/`** — three ready-to-personalize assistant personas, showing the range of what an assistant can be like. Pick one, blend, or invent.
- **`template/`** — the folder skeletons the build instantiates: `assistant-home/` and `hq/`.
- **`pkai-starter/`** — four embedded PKAI starter wikis:
  - `getting-started/` — Claude Code, terminals, viewing your files, Git, GitHub from scratch
  - `git-guide/` — version control without the jargon (optional reading; your assistant handles git for you)
  - `obsidian-reference/` — for Obsidian users (optional)
  - `project-management/` — how to actually work with an AI assistant on real projects
