# Wishlist

Aspirational, not scheduled. Things we'd like V3 to grow into, with no date attached; the dated gaps for a given release are in `CHANGES.md` under *Not in this release, known*. If one of these is yours to do, `CONTRIBUTING.md` says how to offer it.

- **Other harnesses, tested and validated.** V3 is built and tested on Claude Code. A house should be able to run on OpenCode, and on a couple of other harnesses besides, with the kit's claims checked there rather than assumed — which files each harness reads, where its hooks and skills live, what its safety layer does when it blocks. Until that's done, "harness" in these documents means Claude Code.
- **A self-hosted or app version of the shared-pad surface** (MeetingWords), so a house needn't depend on the hosted service.
- **Watcher scripts** for the shapes the *Watchers* chapter describes.
- **A genealogist**: someone, or some house, keeping the whole tree that each lineage block only remembers a little of (the benchmark's `PULL-PROTOCOL.md`).
