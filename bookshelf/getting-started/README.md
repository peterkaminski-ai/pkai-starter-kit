# Getting Started with Claude Code

Welcome! This book walks you through the toolkit your house runs on, from scratch. No experience with terminals or code is needed, and the kit never asks you to use one.

By the end, you'll have:

- **The Claude desktop app** — where your agent lives, in its Code tab
- **A Markdown editor** — for reading and writing your files alongside your agent

Your agent handles the more technical machinery (like git version control) quietly on your behalf. There are optional sections below if you ever want to look under the hood.

## How to Use This Book

If your house is already built, start with **First Day in Desktop**. If you're still getting ready, work through the core path in order. Setup itself takes about half an hour, longer if git has to install.
