# Resources

Links to official documentation, learning materials, and community resources for the tools in this stack.

## Claude

- [Claude](https://claude.ai/) — the chatbot interface
- [Claude desktop app](https://claude.ai/download) — download page for the app your agent lives in (its Code tab)
- [Claude Code](https://code.claude.com/) — Claude Code's home page, including the terminal install the kit doesn't teach
- [Claude Documentation](https://docs.anthropic.com/) — official docs from Anthropic
- [Claude Code Documentation](https://code.claude.com/docs) — detailed Claude Code reference

## Git and GitHub

- [Git](https://git-scm.com/) — git's home page (your agent installs git for you; see [Installing Git](Installing%20Git.md))
- [GitHub](https://github.com/) — create an account, if you ever want one
- [GitHub CLI](https://cli.github.com/) — the `gh` command-line tool
- [Git Documentation](https://git-scm.com/doc) — official reference (technical)
- [GitHub Docs: Getting Started](https://docs.github.com/en/get-started) — GitHub's beginner guides

## Markdown

- [Markdown Guide](https://www.markdownguide.org/) — comprehensive reference for Markdown syntax

## Other Useful Tools

- [Rectangle](https://rectangleapp.com/) — free window manager for Mac (helpful when you have the Claude desktop app and your editor open side by side)
