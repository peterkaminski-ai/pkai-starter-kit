# Project management, and working with your principal

How Pete Kaminski works on projects with Claude Code — and, read from the other side, how an agent works with its principal, the person it belongs to.

This is one book on the shelf that comes with the PKAI starter kit. The other books on the shelf cover individual tools — Git, Claude Code itself, the integrated stack. This one covers the **practice** of using them together to actually get work done.

The bet of this stack is that working with agentic AI is mostly project management. The model does the work; you organize it. Claude Code is powerful enough to make a mess if you don't keep it on rails — and structured enough to be transformatively useful if you do.

## Who this is for

People who already have Claude Code working (and Git, if you chose it), and want to know what to *do* with them. If either of those tools is still new, start with these books on the same shelf:

- [Getting started](../getting-started/README.md) — install everything and get to a working setup.
- [Git guide](../git-guide/README.md) — Git for non-developers.

Once you have the tools, come back here.
