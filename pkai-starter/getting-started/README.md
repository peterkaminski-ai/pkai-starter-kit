# Getting Started with Claude Code

Welcome! This wiki walks you through setting up a modern knowledge-work toolkit from scratch. No prior experience with terminals or code editors is required.

By the end, you'll have:

- **Claude Code** — the AI assistant that works directly with your files, running in a terminal
- **A comfortable terminal** — set up so everything is readable and easy to reach
- **A Markdown editor** — for reading and writing your files alongside your assistant

Your assistant handles the more technical machinery (like git version control) quietly on your behalf — there are optional sections below if you ever want to look under the hood.

## How to Use This Wiki

Start at the top and work through the core path in order. Most people can get set up in under half an hour.

Obsidian is a powerful, free note-taking app that works beautifully with the same Markdown files — very useful, though it may feel like a power-user tool if you're new. It's completely fine to skip it and use Typora or MarkText instead (see [Viewing Your Files](Viewing%20Your%20Files.md)).
