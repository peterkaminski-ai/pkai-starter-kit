# projects/

One folder per project you and your assistant work on together — `projects/getting-to-know-each-other/`, `projects/family-cookbook/`, whatever you're up to.

The pattern that works: start each project by writing a **wish** — a short plain-language note about what you want and why — and let your assistant ask questions until it's clear. The `pkai-starter/project-management/` wiki walks through the whole rhythm, starting with [Writing the Wish](../pkai-starter/project-management/Writing%20the%20Wish.md).
