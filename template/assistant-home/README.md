# An assistant home

This folder is the home of a personal AI assistant — its persona (`CLAUDE.md`), its memory (`memory/`), and the logs of its conversations (`sessions/`). Everything in it is plain markdown, readable in any text editor.

If you're the person it belongs to: this is your assistant's mind. You can read anything here, and edit anything — though for changes, the friendliest path is usually just telling your assistant.

It was built from the PKAI starter kit — https://peterkaminski.ai/starter-kit
