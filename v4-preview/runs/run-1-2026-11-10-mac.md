# Run 1 — 2026-11-10, Mac

- **Release:** v4.0.0-rc.1
- **Machine:** a fresh macOS virtual machine with only a browser installed, and no git or Apple developer tools.
- **Tester:** the kit's author, playing a newcomer, with one observer.
- **Result:** setup finished and the new agent said hello. It took about an hour in all, with narration and some virtual-machine setup; about 30 minutes of that was the kit itself.

## What went well
- The whole setup happened in the desktop app. Terminal never came up.
- The agent noticed Apple's developer tools were missing, started the install, and carried on. When git arrived, it set up version history in both folders by itself.
- The agent checked whether the Documents folder was synced to iCloud before building anything there.

## Where it got stuck or felt clumsy
- **Getting the app.** Once you're signed in on claude.ai, the download link is tucked behind the icon next to your name ("Get apps and extensions"). claude.ai/download goes straight there. The two download buttons, Desktop and Claude Code, give the same app.
- **A brand-new Mac** may show nothing in Spotlight or the Apps view for a while. Finder → Applications works.
- **Signing in again.** The desktop app asks you to sign in even if you're signed in on the web.
- **Where the HQ goes.** The agent asked a three-way question about the folder's location before anything else, which felt confusing.
- **Words.** "Apple's developer tools" came up before any explanation of why. "Scripts that run on every turn" and a "what I'm leaving out" aside read as jargon.
- **The waiver.** A hedged "I guess it's okay" was taken as agreement. It should ask again for a clear yes.
- **Two questions about skills** (how much history, computer or phone) were hard to answer and didn't earn their place.
- **Typing an answer.** Typing a reply instead of picking an option made the agent say the reply hadn't come through, even though it had.
- **Apple's install window** opened behind the app window.
- **The markdown reader question** needs to say plainly what Typora costs, and offer TextEdit as the free fallback.
- **The hand-over** from the setup session to the agent's first session meant moving back and forth between two sessions.
- **The agent's first wake-up** stumbled looking for a note about git that was never written, because git had already arrived.
